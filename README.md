# ☕ Coffee Sales Dashboard | Excel

## 📌 Overview

This project presents an interactive Coffee Sales Dashboard built using Microsoft Excel to analyze sales performance and uncover business insights.

## 📊 Key Metrics

* Total Revenue: $698,812
* Products Sold: 214,470
* Total Orders: 149,116
* Number of Products: 80
* Average Unit Price: 3.4

## 🔍 Dashboard Features

* Revenue Trends by Month
* Sales Distribution by Time of Day
* Quantity Sold and Revenue by Product Type
* Top Selling Products
* Sales by Location
* Sales by Day
* Interactive Category Filters

## 🛠️ Tools Used

* Microsoft Excel
* Pivot Tables
* Pivot Charts
* Slicers
* Data Cleaning
* Dashboard Design

## 📈 Key Insights

* Morning sales accounted for 55% of total sales.
* Hell's Kitchen generated the highest share of sales.
* Revenue showed a consistent increase over the months.
* Coffee products contributed significantly to overall revenue.
